# מבט

אפליקציית מדיה מקומית בסגנון פיד גלילה אנכי.

- בחירת תיקייה אחת או כמה תיקיות.
- תמונות וסרטונים בגלילה למעלה/למטה.
- לייק מקומי על המכשיר.
- שיתוף דרך תפריט השיתוף של Android.
- שמירה לגלריה.
- ללא חשבון, ללא פיד ציבורי, ללא שרת וללא רשת חברתית.

הפרויקט מתעדכן ישירות ב-GitHub, וגרסת Debug נבנית אוטומטית לאחר שינוי ב-main.

## בנייה

GitHub Actions מריץ `gradle assembleDebug` ומעלה את `app-debug.apk` כ-artifact בשם `mabat-debug-apk`.
